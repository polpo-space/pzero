从 2024.04.07 创建的 pzero 项目到 2026.01.01 历经 600 多天的打磨, pzero 终于发布了 v1.0.0 稳定版本.

包含以下重要组件:

* pzero 命令行工具(pzero)
* pzero 核心库(core)
* jzero-admin(基于 pzero 的后台管理系统, 作为 pzero 的最佳实践落地项目)
* jzero-intellij(适配 pzero 的 goland 插件, 极大提升了开发体验感)
