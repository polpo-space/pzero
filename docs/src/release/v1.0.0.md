From the creation of pzero project on 2024.04.07 to 2026.01.01, after more than 600 days of refinement, pzero has finally released v1.0.0 stable version.

Includes the following important components:

* pzero command-line tool (pzero)
* pzero core library (core)
* jzero-admin (backend management system based on pzero, as pzero's best practice implementation)
* jzero-intellij (goland plugin adapted for pzero, greatly enhancing development experience)
